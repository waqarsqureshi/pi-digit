ENGINEERING CAPABILITIES

Hardware-Accurate Emulation on Raspberry Pi

Engineered for embedded Linux education and industrial digital twins. Seamlessly bridges physical hardware interfaces with live web visualization.

8×8 RGB LED Matrix

Directly binds to the Linux framebuffer driver at /dev/fb1. Renders 24-bit TrueColor gamma-corrected pixels with real-time feedback.

Kernel driver: rpi-sense-fb · 16-bit RGB565 /dev/fb1

40-Pin GPIO Expansion

Interactive representation of all 40 physical header pins with pull-up/pull-down resistor states, PWM frequency modulation, and hardware interrupts via /dev/gpiomem.

RPi.GPIO & libgpiod · WiringPi compatible

Environmental Telemetry

Polls live I2C sensors including the HTS221 (Temperature & Relative Humidity), LPS25H (Barometric Atmospheric Pressure), and LSM9DS1 (9-DoF Inertial IMU).

I2C Bus 1 · Addresses 0x5F, 0x5C, 0x6A

16×2 HD44780 LCD Display

Dedicated 16×2 character alphanumeric LCD module with PCF8574 I2C backpack support (address 0x27) for industrial readout programs and curriculum labs.

Hitachi HD44780 controller · I2C backpack 0x27

Embedded Web Terminal & IDE

Live in-browser code editor with multi-tab support for Python and C, integrated with a real interactive Linux shell for compiling and executing code on the Pi.

Python 3 & GCC C99 · Real-time bash stdout/stderr

Hardware Diagnostic Engine

Self-healing diagnostic engine checks kernel overlays, i2cdetect buses, framebuffer paths, and group permissions, reporting precise terminal fix commands.

Automated sysfs probe · One-click clipboard export
SYSTEM ARCHITECTURE

How the Emulator Talks to Hardware

The emulator runs as a lightweight Node.js and Python daemon directly on the Raspberry Pi OS userspace, eliminating latency and bridging local kernel drivers with the web frontend.

1

Hardware Daemon & Kernel Drivers

A background Python daemon polls native Linux sysfs nodes (/dev/fb1, /dev/i2c-1, /dev/gpiomem) using python3-sense-hat and RPi.GPIO.

2

Node.js IPC & WebSocket Engine

The Express backend establishes high-frequency WebSocket streams, synchronizing framebuffer frames, pin toggles, and sensor samples every 500ms.

3

Interactive Twin Frontend

The React digital twin dashboard renders the physical state, allows executing Python/C scripts, and delivers instant visual verification on your browser screen.

sample_sense_hat.py — Native Hardware Execution 
from sense_hat import SenseHat
import time

sense = SenseHat()
sense.clear()

# Display temperature & humidity on 8x8 matrix
temp = sense.get_temperature()
humidity = sense.get_humidity()

print(f"Temperature: {temp:.1f} °C")
print(f"Humidity:    {humidity:.1f} %")

# Draw green heart on 8x8 LED matrix
G = [0, 255, 0]
O = [0, 0, 0]

heart = [
  O, G, G, O, O, G, G, O,
  G, G, G, G, G, G, G, G,
  G, G, G, G, G, G, G, G,
  O, G, G, G, G, G, G, O,
  O, O, G, G, G, G, O, O,
  O, O, O, G, G, O, O, O,
  O, O, O, O, O, O, O, O,
  O, O, O, O, O, O, O, O
]

sense.set_pixels(heart)
time.sleep(2)
STEP-BY-STEP INSTALLATION

Install on Your Raspberry Pi

Follow these quick steps to get the emulator installed, configured, and running on your physical Raspberry Pi.

STEP 1

Clone Repository & Run Automated Installer

Open a terminal on your Raspberry Pi (or SSH into it) and run the installer script:

Terminal (Raspberry Pi OS) 
# Clone repository
git clone https://github.com/waqarsqureshi/pi-digit.git
cd pi-digit

# Run installation script (enables I2C, installs dependencies, sets up systemd)
chmod +x emulator/install.sh
bash emulator/install.sh
View emulator/install.sh on GitHub →
STEP 2

Reboot to Apply Kernel I2C & Framebuffer Overlays

If I2C or Sense HAT kernel modules were just enabled, reboot once to initialize /dev/fb1:

Terminal 
sudo reboot
STEP 3

Set Working Directory (pwd) & Launch Daemon

After rebooting, check that your terminal is in the pi-digit repository folder (cd ~/pi-digit) before executing npm start. The daemon will automatically detect your local IP address:

Terminal 
# 1. Ensure you are in the project folder (required working directory)
cd ~/pi-digit

# Verify current working directory is the repository root
pwd
# Expected output: /home/<user>/pi-digit

# 2. Start the daemon server
npm start

# The server automatically outputs connection URLs on startup:
# ➜ Local Pi (Loopback): http://127.0.0.1:3000/emulator/
# ➜ Network LAN (Wi-Fi): http://<your-pi-ip>:3000/emulator/ (e.g. 192.168.1.xxx)
# ➜ mDNS Hostname:       http://raspberrypi.local:3000/emulator/
